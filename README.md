# Aplikasi Manajemen Tugas Mahasiswa

**Nama:** Judson Phangestu
**NIM:** 2411090
**Kelas:** IFB5A

Aplikasi Android offline untuk mencatat dan memantau tugas kuliah. Data disimpan lokal dengan Room, jadi tetap ada tanpa internet dan tidak hilang saat aplikasi ditutup.

Dibuat dengan Kotlin, Jetpack Compose, ViewModel, Navigation, dan Room.

## Fitur
- Lihat daftar tugas
- Tambah tugas
- Lihat detail tugas
- Edit tugas
- Hapus tugas (dengan konfirmasi)
- Ubah status: Belum, Proses, Selesai
- Filter status dan pencarian

## Cara Menjalankan
1. Clone repository ini.
2. Buka di Android Studio, tunggu Gradle sync selesai.
3. Pilih emulator atau HP, lalu klik Run.
